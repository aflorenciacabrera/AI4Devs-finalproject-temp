    Cómo se firma

    1. Cargá el PDF Queda guardado como versión original (v1).
    2. Elegí el método de firma Con token, remota o propia (demostración).
    3. Elegí el certificado y confirmá con el PIN El PIN se ingresa en tu PC, en Firmadoc Agent.
    4. Descargá el documento firmado Queda como nueva versión vigente; el original se conserva.

      Se guarda como versión original (v1). Al firmar, la versión firmada será la v2 y quedará como vigente.
