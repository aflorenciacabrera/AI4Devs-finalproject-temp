Sistema integrador de ejemplo

Página anfitriona de prueba. Recibe la signing_url en el fragmento (#signing_url=...&mode=iframe|component|popup): el fragmento no llega al servidor que entrega esta página. En un sistema real la signing_url la obtiene el backend del integrador (con su API key) y se la entrega al navegador.
